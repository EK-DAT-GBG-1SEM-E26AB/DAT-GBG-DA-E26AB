# Git i IntelliJ

Fire korte vejledninger til Git, som I kan bruge hele semesteret. Vi bruger Git **fra IntelliJ**.
Terminalen lærer I også, men alt, hvad I skal bruge til projekterne, kan klares med knapperne i
IntelliJ.

| Vejledning | Læs den … |
| --- | --- |
| [1. Hvad Git gør](hvad-git-goer.md) | først. Uden billedet i hovedet giver knapperne ingen mening. |
| [2. Git i IntelliJ – trin for trin](git-i-intellij.md) | når du skal lære knapperne. Små bidder, én ting ad gangen. |
| [3. Gode vaner](gode-vaner.md) | før I begynder at arbejde i grupper. De fleste konflikter kan undgås. |
| [4. Nødhjælp](noedhjaelp.md) | **når noget går galt.** Find din situation og følg trinene. |

> **Du kan næsten ikke miste noget.** Så længe du har committet, ligger dit arbejde i Git. Og
> selv det, du ikke har committet, gemmer IntelliJ i sin egen **Local History**. Se
> [Nødhjælp](noedhjaelp.md#e-min-kode-er-væk).

Genveje i vejledningerne er skrevet til Windows. På Mac: brug <kbd>Cmd</kbd> i stedet for
<kbd>Ctrl</kbd>. <kbd>Alt</kbd>+<kbd>9</kbd> og <kbd>Alt</kbd>+<kbd>0</kbd> hedder
<kbd>Cmd</kbd>+<kbd>9</kbd> og <kbd>Cmd</kbd>+<kbd>0</kbd>.
